# Mondkalender

Günstige Tage nach dem Mondkalender (Tradition nach Paungger/Poppe) für Körperpflege, Haushalt und Garten.
Läuft komplett im Browser, rechnet den Mondstand selbst (Meeus) und funktioniert nach dem ersten Öffnen auch offline.

**App öffnen:** https://kraftste.github.io/mondkalender/

**Auf dem iPhone installieren:** Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Die Regeln sind am Original („Der Mondkalender“, App Store) kalibriert: 266 von 266 geprüften Tagesbewertungen stimmen überein (Oktober/November 2026).
Eine Wirkung des Mondstands ist wissenschaftlich nicht belegt.
